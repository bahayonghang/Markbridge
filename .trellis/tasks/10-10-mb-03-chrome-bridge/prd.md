# 03 Chrome 扩展配对与实时同步

## 目标

实现 Chrome MV3 扩展与 Tauri 本机配对、认证、完整树和增量事件同步、心跳、持久重连及实时状态。只同步读取，浏览器变更引擎留给 06。

## 归属、状态与依赖

父任务：[Markbridge 工作台](../10-10-markbridge-workspace/prd.md)。需求：R02,R03。里程碑：M1。状态：planning，未开始产品实现。

前置：[02](../10-10-mb-02-identity-storage-protocol/prd.md)。依赖代表前置验收通过，不能仅凭目录存在或任务已创建启动。该任务属于 Windows 首版。

## 范围

该任务只承担上述交付；跨设备云服务、自动公共发布和无确认浏览器变更不在范围。拟修改路径与接口由 [设计](design.md) 说明。

## 验收标准

- [ ] AC03-1：两个临时 Profile 配对后各自独立；错误令牌/Origin/版本/资料绑定全部拒绝且零数据写入。
- [ ] AC03-2：Chrome 中新增/修改/移动/删除/排序和导入产生正确缓存；无固定三根假设。
- [ ] AC03-3：worker 强制停止、重启浏览器、ack 不适用但事件断档/乱序/重复均收敛至正确全树。
- [ ] AC03-4：吊销配对立即关闭权限；断开显示只读，重连校验后才标 live；空闲 5 分钟后连接仍能接收事件。

对应父级 [验证矩阵](../10-10-markbridge-workspace/verification.md)：V02、V03（缓存侧）、V04。未运行环境明确保留 NOT_RUN，不能以源码检查代替原生证据。

## 完成条件

实现、相关检查和必要原生步骤均满足后才可标完成。检查命令和回退见 [执行计划](implement.md)。任务创建只授权规划，最终方案待用户批准后才进入实现。
