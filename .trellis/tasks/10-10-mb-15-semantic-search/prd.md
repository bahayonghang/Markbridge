# 15 可选本地向量检索

## 目标

后续可选本地语义检索：用户启用后为选中摘要/标题建立向量索引，提供语义查询并可彻底删除派生索引。默认关闭且不阻塞 Windows 首版。

## 归属、状态与依赖

父任务：[Markbridge 工作台](../10-10-markbridge-workspace/prd.md)。需求：R16。里程碑：M5。状态：in_progress，2026-10-13 实现、独立检查及当前原生合成功能通过；缺实际 embedding 模型和人工标签，V18/AC15-3 未完成。

前置：[12](../archive/2026-10/10-10-mb-12-library-maintenance/prd.md)、[13](../10-10-mb-13-windows-acceptance/prd.md)。依赖代表前置验收通过，不能仅凭目录存在或任务已创建启动。该任务为后续范围，不阻塞 Windows 首版。

本次按用户批准的 13 启动例外推进：当前 Windows 安装/诊断/自动检查已经通过。15 不依赖 14。14 随后按用户对其他平台的决定离开活动队列，这不改变本任务。用户确认暂无本地 embedding 模型，实施和确定性检查继续，真实质量/性能 V18 保持 NOT_RUN，不能关闭本任务。

## 范围

该任务只承担上述交付；跨设备云服务、自动公共发布和无确认浏览器变更不在范围。拟修改路径与接口由 [设计](design.md) 说明。

## 验收标准

- [x] AC15-1：默认零 embedding 请求；启用前说明模型、数据范围和空间影响。
- [x] AC15-2：索引可暂停/恢复，书签删除或摘要更新可失效重算；模型/维度变化不混用。
- [ ] AC15-3：20 条人工标注查询在固定模型达到 Recall@5 >=0.8，B10K 暖态 p95 <=1 s；保留低于门槛结果。
- [x] AC15-4：禁用或删除索引后普通搜索、标签和摘要保留；无本地模型时功能明确不可用。

AC15-1/2/4 的功能证据见 [当前收据](evidence/receipts.md)，包含确定性、浏览器和最终 4fc 原生合成模型检查。AC15-3/V18 仍需实际模型与人工标签，不关闭任务。

对应父级 [验证矩阵](../10-10-markbridge-workspace/verification.md)：V18。未运行环境明确保留 NOT_RUN，不能以源码检查代替原生证据。
