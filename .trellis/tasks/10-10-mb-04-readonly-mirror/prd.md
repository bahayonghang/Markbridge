# 04 只读文件镜像与离线恢复

## 目标

实现 Chrome 文件只读镜像、Profile 枚举、断线缓存浏览和在线/文件来源协调。保持用户数据读取权限和来源身份清晰。

## 归属、状态与依赖

父任务：[Markbridge 工作台](../10-10-markbridge-workspace/prd.md)。需求：R03。里程碑：M1。状态：planning，未开始产品实现。

前置：[02](../10-10-mb-02-identity-storage-protocol/prd.md)、[03](../10-10-mb-03-chrome-bridge/prd.md)。依赖代表前置验收通过，不能仅凭目录存在或任务已创建启动。该任务属于 Windows 首版。

## 范围

该任务只承担上述交付；跨设备云服务、自动公共发布和无确认浏览器变更不在范围。拟修改路径与接口由 [设计](design.md) 说明。

## 验收标准

- [ ] AC04-1：单/多 Profile 正确枚举；未授权或不存在路径显示可恢复错误，不扫描其他浏览器私有数据。
- [ ] AC04-2：原子替换、半写 JSON、文件暂失、目录重命名/不可访问均不清空最后有效缓存。
- [ ] AC04-3：关联错误/不一致的文件源不能获得在线写权限；标签不会按相同 URL 串到另一个 Profile。
- [ ] AC04-4：Chrome 关闭时可浏览最后有效树，Bookmarks 与 Local State 文件哈希在应用操作前后不被本程序改写。

对应父级 [验证矩阵](../10-10-markbridge-workspace/verification.md)：V04、V05。未运行环境明确保留 NOT_RUN，不能以源码检查代替原生证据。

## 完成条件

实现、相关检查和必要原生步骤均满足后才可标完成。检查命令和回退见 [执行计划](implement.md)。任务创建只授权规划，最终方案待用户批准后才进入实现。
