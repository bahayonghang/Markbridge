# S01 蓝色书签桥接品牌图标

## 目标与启动门槛

实现父任务U01，以内置image生成功能创建体现Markbridge书签及桥接的蓝色品牌，统一用户看到的应用/扩展标识。初轮仅规划；2026-10-13用户明确“请按照trellis任务顺序实施”，现已批准父任务最新规划并启动本任务。本子任务不依赖S02/S03。

## 要求

采用父visual-design中的A/B方向，先生成候选与真实小尺寸对比，展示并记录最终选择，再替换。生成母版、prompt、派生关系可追溯。必须实际使用image_gen，不能以CSS/SVG临摹或尺寸转换替代生成。

覆盖Windows程序图标、应用侧栏品牌和Chrome扩展icons/default_icon。功能线形图标不改，扩展权限、协议、安装和发布不变。

## 验收

- [x] AC-S01-1：有内置image_gen生成记录、A/B候选、prompt和最终选择；16/24/32/48/128/256浅/深底辨识，符合蓝色/书签/桥接，无文字/水印/白边。
- [x] AC-S01-2：母版和最终本地资产进仓库；PNG真实alpha、ICO包含所需多尺寸，同源可重导出；消费端不依赖工具默认目录。
- [x] AC-S01-3：桌面/侧栏/扩展引用存在且构建通过；扩展16/32/48/128 PNG有效，权限列表和CSP不变。
- [x] AC-S01-4：新Windows exe自有标题栏/任务栏及临时Chrome扩展展示同一品牌，记录hash/尺寸和原生证据，未测项不标PASS。
