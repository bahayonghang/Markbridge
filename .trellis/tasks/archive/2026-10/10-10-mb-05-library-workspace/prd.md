# 05 书签工作台、搜索与多 Profile

## 目标

建立可使用的多 Profile 工作台：目录树、虚拟列表、标题/URL 搜索、详情、键盘导航与连接/同步状态。达到 M1 可用闭环。

## 归属、状态与依赖

父任务：[Markbridge 工作台](../10-10-markbridge-workspace/prd.md)。需求：R04。里程碑：M1。状态：planning，未开始产品实现。

前置：[03](../10-10-mb-03-chrome-bridge/prd.md)、[04](../10-10-mb-04-readonly-mirror/prd.md)。依赖代表前置验收通过，不能仅凭目录存在或任务已创建启动。该任务属于 Windows 首版。

## 范围

该任务只承担上述交付；跨设备云服务、自动公共发布和无确认浏览器变更不在范围。拟修改路径与接口由 [设计](design.md) 说明。

## 验收标准

- [ ] AC05-1：B10K 导入后树/列表/详情一致，重复 URL 保留独立条目，中文/长标题不破坏布局。
- [ ] AC05-2：P2 来回切换 20 次无旧结果串入；断线/重连和空库状态有明确信息。
- [ ] AC05-3：V03 的 100 次在线变化在 UI 3 秒内可见且最终树等价。
- [ ] AC05-4：V06 暖态搜索和冷启动目标达标，键盘导航与可见焦点有实际交互证据。

对应父级 [验证矩阵](../10-10-markbridge-workspace/verification.md)：V03、V06。未运行环境明确保留 NOT_RUN，不能以源码检查代替原生证据。
