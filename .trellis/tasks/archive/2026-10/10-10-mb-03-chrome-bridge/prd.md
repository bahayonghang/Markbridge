# 03 Chrome 扩展配对与实时同步

## 目标

实现 Chrome MV3 扩展与 Tauri 本机配对、认证、完整树和增量事件同步、心跳、持久重连及实时状态。只同步读取，浏览器变更引擎留给 06。

## 归属、状态与依赖

父任务：[Markbridge 工作台](../../../10-10-markbridge-workspace/prd.md)。需求：R02,R03。里程碑：M1。状态：completed；2026-10-13 按已有 AC 证据及同一真实睡眠项的用户豁免结案。

前置：[02](../10-10-mb-02-identity-storage-protocol/prd.md)。依赖代表前置验收通过，不能仅凭目录存在或任务已创建启动。该任务属于 Windows 首版。

## 范围

该任务只承担上述交付；跨设备云服务、自动公共发布和无确认浏览器变更不在范围。拟修改路径与接口由 [设计](design.md) 说明。

## 验收标准

- [x] AC03-1：两个临时 Profile 配对后各自独立；错误令牌/Origin/版本/资料绑定全部拒绝且零数据写入。
- [x] AC03-2：Chrome 中新增、修改、移动、删除和排序进入该 Profile 的缓存，子节点顺序与 Chrome 树一致；无固定三根假设。本机读取使用已同步缓存上的 `tree`、`list`、`search`、`get`、`count`。验收不使用 HTML 导入或导出。
- [x] AC03-3：worker 强制停止、重启浏览器、ack 不适用但事件断档/乱序/重复均收敛至正确全树。
- [x] AC03-4：吊销配对立即关闭权限；断开显示只读，重连校验后才标 live；空闲 5 分钟后连接仍能接收事件。

对应父级 [验证矩阵](../../../10-10-markbridge-workspace/verification.md)：V02、V03（缓存侧）、V04。2026-10-11 确定本机读取不接入 MCP，不注册 Native Messaging host，不把 HTML 导入或导出当作读取或验收步骤。扩展仍用 `chrome.bookmarks` 把整树和增量写入缓存。V03 的界面可见由 05 测量。未运行环境明确保留 NOT_RUN，不能以源码检查代替原生证据。
