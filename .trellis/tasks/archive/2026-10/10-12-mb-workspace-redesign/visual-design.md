# Markbridge 视觉规范

## 1. 主题

视觉主张：中性浅色底、清晰蓝色选中态、紧凑从容的桌面书签工作台。借鉴 Codex 内容优先与 Apple 克制层次，保留 Windows 原生标题栏，不仿 macOS 红绿灯或玻璃效果。

内容主张：定位来源/目录，浏览搜索，按需详情，再操作。无营销 hero、统计卡片墙或首屏配置。
交互主张：高频导航及键盘无动画；指针按钮短促按压；偶发详情仅 opacity/transform 140ms，减少动态关闭。识别点是蓝色选中行与书签内容层级。

## 2. 颜色

| 角色 | 基准色 | 用途 |
|---|---|---|
| canvas | #F3F5F8 | 窗口底 |
| sidebar | #ECEFF4 | 侧栏 |
| surface | #FFFFFF | 主区与详情 |
| ink | #202733 | 正文 |
| muted | #606B7C | 次要文字 |
| blue | #1767D2 | 主要动作/焦点 |
| selected | #E8F0FE | 选择背景 |

| danger | #B43438 | 删除/错误 |
| caution | #895C16 | 只读警示 |

变量为唯一来源，派生色以 OKLCH 调亮度并实测对比度。正文至少 4.5:1、焦点/关键非文字至少 3:1。状态带文字，不只靠色点。

## 3. 字体

品牌词：清晰、安静、精确。选择 "Segoe UI Variable Text", "Segoe UI", "Microsoft YaHei UI", "Microsoft YaHei", sans-serif，适应 Windows 中英混排，不使用网络字体。表单显式继承，避免默认字体混入。

| 角色 | 字号/行高 px | 字重 |
|---|---|---|
| 产品名 | 17/24 | 650 |
| 工作区标题 | 22/30 | 600 |
| 书签标题 | 14/22 | 500 |
| 控件/正文 | 13/20 | 400/500 |
| 辅助信息 | 12/18 | 400 |
| 详情段落 | 13/23 | 400 |

中文零字距、lang=zh-CN；计数 tabular-nums。列表标题可视觉截短但详情可读全；动作、状态、计数不尾部省略。URL 主行 host、详情完整 URL。

## 4. 组件

控件 7px、导航选中 8px、聚焦对话框 12px，短标签才用 pill。按钮默认/hover/pressed/focus/disabled 齐全，禁用原因就近显示。危险确认红色，普通删除工具按钮中性。

交互目标至少 40×40px；checkbox 16px 放独立 40px 单元，禁止共用文字输入宽度。输入高 40px、书签行 52px、树行 40px，尺寸与虚拟化一致。单套 18px 线形图标，不混 emoji。

多选替换工具条为「已选 N 项 / 移动 / 标签 / 删除 / 取消」。普通编辑用内容区/详情，仅破坏性确认与必须处理的未保存草稿锁焦点。

## 5. 布局

间距 4/8/12/16/24/32px。height:100dvh，分区 min-height:0 独立滚动，不以 body 承载所有内容。侧栏216px、详情312px、列表至少440px。路径条56px、工具行64px、底部状态32px。左对齐，主动作不过度重复。

## 6. 层次

灰侧栏、白主区、白详情，背景差加1px分隔。无阴影卡片；菜单/浮层才用 0 8px 28px #20273318。无渐变、磨砂、厚侧边强调或卡片堆叠。

## 7. 准则

- 首屏主角是书签，不是模型/端口/节点 ID。
- 蓝色只用于选择、焦点和主要操作。
- 动作名一致，成功必须对应回执。
- 设置和整理是页面，不用弹窗解决普通溢出。
- 搜索范围、多选范围持续可见。
- 无 transition:all、布局属性动画或键盘动画。
- 无第三方字体/图标请求，列表不隐式泄露书签域名。

## 8. 响应与可访问性

≥1100px：216侧栏+弹性列表+可选312详情。800–1099px：侧栏保留，详情替换主区、有返回。640–799px：64px导航轨，文件夹或详情是主区独立视图，有返回。保留原生最小640×480，不承诺移动平台。

验证1440×900、1100×760、640×760、1100×480、640×480，另记录Windows125%/150%缩放。跳至内容为首焦点；树/列表语义清晰、焦点可见；Escape恢复触发焦点；快捷键不抢文本输入；无焦点陷阱。

## 9. 实现提示

- 书签行：白底52px，标题14/22px 500，站点12/18px #606B7C，水平16px，40px选择区，selected #E8F0FE，focus 2px #1767D2，无动效。
- 来源按钮：216px侧栏内左右12px，高40px、7px圆角，13/20px 500，状态文字可读。
- 表单：白底24px内距，13/20px标签，40px输入7px圆角，字段下报错；主按钮#1767D2，指针按下scale(.98)100ms，reduced-motion关闭。
- 设置：24px内距，22/30px 600标题，组间32px，控件间12px，无阴影卡片与密钥明文。

原型内容是标注的合成数据；产品接入替换为已验证DTO，示例连接状态/数量不能成为真实运行结果。
