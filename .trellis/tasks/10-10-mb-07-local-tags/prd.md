# 07 本地标签与可选标题编码

## 目标

实现默认本地标签、备注、过滤、多选标签操作和显式启用的标题编码。保留用户现有书签名称与分隔符。

## 归属、状态与依赖

父任务：[Markbridge 工作台](../10-10-markbridge-workspace/prd.md)。需求：R06。里程碑：M2。状态：in_progress。验收记录在 [证据](evidence/receipts.md)。

前置：[06](../archive/2026-10/10-10-mb-06-safe-editing/prd.md)。依赖代表前置验收通过，不能仅凭目录存在或任务已创建启动。该任务属于 Windows 首版。

## 范围

该任务只承担上述交付；跨设备云服务、自动公共发布和无确认浏览器变更不在范围。拟修改路径与接口由 [设计](design.md) 说明。

## 验收标准

- [x] AC07-1：离线也可增删改标签与备注、筛选和多选；Chrome 标题和 URL 完全不变。
- [x] AC07-2：大小写/空白/Unicode 归一去重一致，标签合并/删除可以恢复关联。
- [x] AC07-3：用户启用标题编码后仅选中条目修改；竖线、反斜线、空标签、重复应用均可逆。
- [x] AC07-4：外部手改编码标题后显示冲突；禁用编码不会未经确认批量重命名。
