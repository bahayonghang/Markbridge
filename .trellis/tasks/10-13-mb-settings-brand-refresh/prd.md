# Markbridge 蓝色品牌图标与设置体验优化

## 目标与授权

让品牌图标体现“书签与桥接”，让设置在大屏和最小窗口中都容易查找、阅读和操作，并允许用户调整外观。

2026-10-13用户要求结合ui和frontend-design深入分析并创建Trellis优化任务。初轮交付研究与规划。随后用户明确“请按照trellis任务顺序实施”，批准最新规划及S01→S02→S03实施顺序；implementation_approval=granted。提交、归档及日常安装仍未授权。

| U02 | 设置分类位于内容区左侧独立栏，包含通用、Chrome连接、AI、语义检索、备份导出，取消顶部横向Tab | S02、S03 |

| U04 | 提供跟随系统/浅色/深色主题、系统默认/微软雅黑/宋体字体预设、小/标准/大字号，即时应用且重启保留 | S03 |

## 验收标准

- [x] AC-P1：图像生成来源、候选、最终母版和消费映射可追溯；程序、侧栏和扩展同一标识，16/32px可辨识，无白边或透明棋盘。
- [x] AC-P2：五类设置位于左栏，纵向键盘导航有效；历史导出共享当前来源，分类切换不清空库查询、选择或未保存内容。
- [x] AC-P3：五页使用完整内容栏，宽连接页为两列；1440×900、1100×760、640×760、1100×480、640×480和1920×1080无整页溢出、重叠或不可达操作。
- [x] AC-P4：三项偏好即时生效且真实桌面重启保留，只有system响应系统主题；恢复默认只影响外观。
- [x] AC-P5：大字号虚拟列表、键盘浏览和checkbox焦点正确；浅/深色文字、控件、状态与焦点可读，状态不只靠颜色。
- [x] AC-P6：自动、浏览器和原生证据分层记录；导航及外观变化不产生模型/抓取/索引/浏览器写入；缺证据保留NOT_RUN/UNVERIFIED。

分项判据见verification.md，依赖见task-map.md。

## 范围外与边界

不含全工作台结构重设计、网络字体、字体扫描/导入、多套皮肤、远程网页或扩展设置页外观同步、非Windows支持、算法/提供商变化、侧车迁移或全库恢复。保留单一bridge、Rust SQLite写入权、扩展浏览器写入权、明确apply、AI/语义默认关闭和preview隔离。扩展只统一图标，不改协议或权限。

不提交、归档、push、签名、发布或日常安装，不改真实Chrome配置、书签或已安装扩展。既有安装重测授权不自动扩展至本任务新产物。
