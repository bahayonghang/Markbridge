# 13 Windows 集成验收与本地安装包

## 目标

完成 Windows 首版跨任务验证、性能与故障恢复回执、使用文档、诊断导出和本地安装包验证。交付可审阅安装产物，不自动发布。

## 归属、状态与依赖

父任务：[Markbridge 工作台](../10-10-markbridge-workspace/prd.md)。需求：R01,R14。里程碑：M4。状态：planning，未开始产品实现。

前置：[09](../archive/2026-10/10-10-mb-09-webpage-preview/prd.md)、[12](../archive/2026-10/10-10-mb-12-library-maintenance/prd.md)。依赖代表前置验收通过，不能仅凭目录存在或任务已创建启动。该任务属于 Windows 首版。

## 范围

该任务只承担上述交付；跨设备云服务、自动公共发布和无确认浏览器变更不在范围。拟修改路径与接口由 [设计](design.md) 说明。

## 验收标准

- [ ] AC13-1：01–12 各项必要证据可追溯；V01–V15 全部通过或明确 FAIL，不把缺失运行项当完成。
- [x] AC13-2：Windows 全新隔离用户数据环境可安装、配对、同步、双预览、编辑、AI（具备模型时）、恢复并正常退出。
- [x] AC13-3：B10K 的同步/搜索/冷启动实测给出原始数据与 p50/p95/max，符合门槛或明确未满足。
- [x] AC13-4：本地安装包校验 hash、文件内容和运行版本，卸载/升级说明保护用户数据；未发布、未签名状态明确。
- [ ] AC13-5：Floccus 在专用库有实际人工传播证据才声明已验证；缺少环境单独标 UNVERIFIED，不阻塞基础本地功能结论。

对应父级 [验证矩阵](../10-10-markbridge-workspace/verification.md)：V01–V15；V16 独立外部证据。未运行环境明确保留 NOT_RUN，不能以源码检查代替原生证据。

实现、相关检查和必要原生步骤均满足后才可标完成。检查命令和回退见 [执行计划](implement.md)。当前规划已获实施批准；前置验收通过后才可启动该子任务。提交、归档、发布和日常安装仍需单独授权。
