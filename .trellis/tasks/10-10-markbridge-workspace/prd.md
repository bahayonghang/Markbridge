# Markbridge 本地书签工作台

## 目标与状态

建立本地优先的 Tauri 桌面应用，连接 Chrome 书签，提供实时查看、编辑、标签、网页预览和 AI 整理。2026-10-10 用户已批准按当前规划开始实施。父任务负责协调；子任务按依赖和验收门槛依次启动，01 为首个目标。

用户已授权完成 bootstrap、创建父子任务，并批准当前规划的实施。用户另已确认：两种预览都需要；标签默认本地保存，可选写入标题；Windows 首版，macOS／Linux 后续适配。提交、归档、发布和日常环境安装仍需单独授权。

## 当前事实

规划建立时仓库只有 Trellis 脚手架和参考文档。`00-bootstrap-guidelines` 已完成；01 已创建工程基础源码，原生交互保持 UNVERIFIED。02 的共享协议与 SQLite 模块已通过本地验收，桌面尚未接入数据库。尚无配对或书签功能。当前结论见 [实施状态](execution-status.md)。`ref/Markbridge-实施方案.md` 是设计输入且被 Git 忽略，本文保留独立执行所需需求。技术纠错和来源见 [research/technical-findings.md](research/technical-findings.md)。

## 需求与验收

| ID | 需求 | 可观察验收 | 主要任务 |
|---|---|---|---|
| R01 | Windows 本地桌面应用与配套扩展 | 可从文档构建、启动并完成首次配对；本地数据重启后保留；安装包可在隔离用户环境启动 | 01、13 |
| R02 | 多 Chrome Profile | 两个测试 Profile 存在相同节点 ID 时，展示、标签、操作和回滚互不串用；切换 Profile 后旧异步结果不显示 | 02、03、05 |

| R10 | AI 批量重分类 | 两遍分类方案、逐项接受/拒绝、预计影响与顺序可审查；100 条应用后可恢复语义树和顺序；中断后可定位已执行范围 | 11 |
| R11 | 可恢复操作 | 写前快照和可读备份；失联不误报成功；重启可恢复操作记录；撤销不会覆盖后来发生的外部修改 | 06、11 |
| R12 | 隐私与安全边界 | 默认不发送 AI 请求；远程端点需用户配置；日志无密钥/正文/完整敏感 URL；抓取不能跳转到受禁地址；预览与可信 UI 隔离 | 03、08、09、10 |
| R13 | 本地库优化 | 重复项和死链只生成建议；403/429/超时不当作死亡；摘要可搜索；删除需审查并支持恢复 | 12 |
| R14 | Windows 发布候选验证 | 功能、恢复、性能、权限和安装证据齐全；未运行项单独列出；Floccus 传播只在专用测试库中人工验收 | 13 |

实时指标适用于应用和 Chrome 均运行、配对有效且状态为 live 的期间。系统休眠、浏览器关闭、扩展被暂停和网络网页加载时间不计入 3 秒指标。恢复过程必须显示状态，不得伪装 live。

## 范围与阶段

M1 提供本地同步和可用书签浏览；M2 提供人工编辑、标签及两种预览；M3 提供 AI 单条和批量整理；M4 提供库维护与 Windows 验收。M1–M4 共 13 个子任务构成 Windows 首版。

M5 的跨平台与语义检索各自为后续子任务，不阻塞 Windows 首版。父任务只有 15 个子任务完成，或用户明确调整范围后，才能整体完成。Windows 首版可以单独达到里程碑完成。

不包含新的跨设备云同步服务、自动无确认 AI 写回、直接改写 Chrome 文件、自动同步浏览器 Cookie、全浏览器兼容承诺、扩展商店发布或自动发布安装包。Floccus 继续管理自己的跨设备数据；本地侧车不随 Chrome 书签自动跨设备迁移。
