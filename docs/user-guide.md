# Markbridge（签桥）操作指南

Markbridge 把本地 Chrome 书签放进一个桌面工作台：左侧浏览文件夹，中间搜索和选择书签，按需打开详情。侧栏的「整理」「操作历史」「设置」处理低频操作。

这份指南对应新版工作台当前源码。Windows 首版的验收目标是 Windows 11 x64、Chrome 134 及以上；当前构建、原生与安装结果及缺失证据见 [13 集成验收](../.trellis/tasks/10-10-mb-13-windows-acceptance/evidence/current-integration-2026-10-13.md)，改版历史证据见 [R08 记录](../.trellis/tasks/archive/2026-10/10-12-mb-r08-acceptance/evidence/receipts.md)。本轮没有发布安装包、安装到日常环境或上架扩展。macOS/Linux 源码适配与可选语义检索实现仍待实际平台/模型验收，不能视为已支持或质量已达标；任意全库导入恢复不在已交付范围。开发与验收使用临时 Chrome 资料和独立应用数据目录。

## 连接 Chrome

一个 Chrome 用户资料就是一份独立书签来源。给资料起容易识别的名称，例如「工作」和「个人」；名称不会把两份资料合并。

1. 首次打开选择「连接 Chrome」。之后可从「设置 → Chrome 连接」进入。
2. 在准备接入的 Chrome 资料中打开 `chrome://extensions`，启用开发者模式，选择「加载已解压的扩展程序」，载入与桌面版配套的 Markbridge 扩展目录。从源码构建时该目录为 `apps/extension/dist`。
3. 在桌面点击「启动连接」。默认端口为 49153；提示占用时，展开「高级：连接端口」，换一个可用端口后重试。
4. 填写「资料名称」，点击「生成配对串」，复制到扩展的「配对设置」。配对串有效期为 120 秒；过期后回到桌面重新生成。
5. 核对桌面显示的扩展身份和来源与扩展选项页一致，点击「确认此扩展」。等待书签树核对完成。
6. 在「书签来源」中选中这份资料。显示「实时同步」后，可以预览并确认书签变更。

**更新桌面版时，同时更新配套扩展。** 新版移动和删除会核对审查过的整个子树（协议字段 `expectedSubtree`）。旧版扩展会拒绝不认识的新字段，单独替换桌面版不能视为兼容升级。应用不会自动安装扩展。

| 来源状态 | 可以做什么 | 恢复方式 |
| --- | --- | --- |
| 实时同步 | 浏览、本地保存、审查并确认 Chrome 变更 | 保持桌面与对应 Chrome 运行 |
| 连接中／核对中 · 只读 | 浏览已有缓存，等待核对 | 在连接设置和扩展中查看进展 |
| 缓存／连接错误／未连接 · 只读 | 浏览缓存、导出；已配对缓存资料可保存本地标签和备注 | 打开对应 Chrome 并启用扩展，点击「重新连接」 |
| 未配对 · 只读 | 查看保留的本地缓存 | 重新生成配对串并确认 |

断线时不会把浏览器修改排队，重连也不会自动重放。结果不确定的操作先在「操作历史」核对。扩展显示已连接后，仍以桌面的「实时同步」状态判断能否写入。

「吊销配对」需要再次确认。它终止此配对，保留本机缓存、标签和备注。

配对或模型密钥保存提示本机存储不可用时，检查应用数据目录权限，并确认系统凭据服务可用且已解锁，再重试。应用不会改用明文保存密钥；只有保存完成才显示成功。各平台安全存储前提见 [原生平台指南](native-platforms.md)。

### 只读浏览文件

首次页或「设置 → Chrome 连接」选择「只读浏览文件」，填写 Chrome 的用户数据目录，点击「枚举资料」，再对目标资料选择「接入只读镜像」。应用只读取书签文件，不直接改写它。

填写包含 `Local State` 和各资料子目录的绝对路径。可在目标 Chrome 的 `chrome://version` 查看「Profile Path」，使用其上一级目录；环境变量与 `~` 需要展开为实际绝对路径。各系统默认目录、依赖和未验证平台见 [原生平台指南](native-platforms.md)。

文件镜像可浏览、搜索标题或网址、导出 HTML；独立镜像没有本地侧车功能。文件陈旧或不可用时仍显示最后缓存和来源状态。可在设置中「重新读取」，也可「停止监听」。「验证关联」用于核对文件来源与已配对资料的关联，不会授予文件镜像写入权限。

## 浏览、搜索和选择

在左侧文件夹树切换目录，路径栏显示当前位置。列表保留 Chrome 中的顺序；单击选中并查看详情，双击或 Enter 进入目录或打开 HTTP/HTTPS 书签。长标题和完整网址可在「详情 → 信息」阅读。

搜索框默认查找标题和网址。展开「筛选」可选「全部书签」或「当前目录及后代」，再叠加标签；文本、目录和标签条件取交集。「更多搜索范围」可显式包含本地摘要或备注。文件镜像只使用已有标题和网址。点击「清空筛选」回到未筛选状态。

结果分批加载，每页 200 项不是搜索结果总上限。查看「已加载／总数」，需要时点击「加载下一页」；在列表内按 Ctrl+End 可加载至末尾。

| 操作 | 效果 |
| --- | --- |
| Ctrl+单击或勾选行首复选框 | 增减当前选择 |
| Shift+单击、Shift+方向键 | 扩展连续选择 |
| 列表内 Ctrl+A | 选择当前已加载的结果，范围和数量持续显示 |
| 方向键、Home、End | 移动树或列表焦点 |
| 文件夹树的左右方向键 | 展开、收起或返回父级 |
| Alt+上／下方向键 | 生成当前条目的排序预览，确认后才写入 |
| Escape | 关闭可关闭的详情或确认框，返回触发控件 |

切换目录、查询、筛选或来源会清除旧多选，避免隐藏项进入下一次操作。小窗中的「文件夹」「详情」切换为主区视图，使用「返回列表」或关闭详情返回。

## 新建、编辑、移动和删除

新建无需先选中书签。在可写目录中点击「新建」，选择「书签」或「文件夹」，填写名称；书签还需填写网址。通过目标文件夹选择器确认路径，再点击「预览新书签」或「预览新文件夹」。

选中已有条目后，在「详情 → 信息」修改「新标题」「新网址」，点击「预览修改」。移动时点击「移动」，展开目标文件夹选择器，可按完整路径搜索；选择目标后点击「预览移动」。「上移」「下移」调整同级顺序。「预览删除」会列出影响范围。

所有这些操作先显示差异。检查名称、网址、位置及数量后点击「确认变更」；取消预览不会写入。较大删除会再要求一次确认。根目录、浏览器管理的特殊目录及受保护内容不能移动或删除。

输入不会因切到整理、历史或设置而直接写入。切换来源或离开未保存的本地草稿时，按提示选择继续编辑或放弃；已保存内容仍留在原来源。若外部修改使预览过期，重新读取并审查差异。

### 多选操作

勾选后，工具条显示待处理数量和「移动所选」「标签」「删除所选」「取消选择」。检查已加载范围和选择数量再继续。

- **移动或删除：** 查看完整路径和影响数量，预览后确认。父子同时选中时按实际子树去重，数量包含受影响的后代。单次日常删除最多 1000 个去重后的子树节点；超限需缩小选择后重新审查。
- **共同标签和备注：** 「标签」打开所选项目的共同编辑区。保存备注会应用到所有所选项目；已有备注不同会提示，请先核对。
- **执行结果：** 批次开始前先保存快照及 HTML／侧车备份，备份失败就取消浏览器变更。查看逐项回执；出现冲突、断线或不确定时停止后续步骤。停止只影响剩余步骤，已完成部分要通过条件撤销处理。

## 标签、备注和预览

「详情 → 标签备注」可添加或移除本地标签、保存备注，以及管理标签名称和合并。默认只保存在本机，不改 Chrome 标题；断连后的已配对缓存资料仍可使用。本地标签变更可通过「撤销上次标签变更」处理。

需要把标签带入浏览器同步时，展开「可选：将标签写入标题」，显式启用标题编码，点击「预览标题差异」。逐项确认 `名称 | tag1 | tag2` 的完整结果后再写入。关闭编码不会自动还原标题；需要还原时先「预览恢复原标题」。原有、未被认领的竖线内容不会自动拆成标签。

「内容预览」按所选书签读取摘要或缓存正文，显示来源和缓存时间；可「重新读取」或「取消」。这不是全库后台抓取。公共网页抓取不接受本机、私网等受限地址；无法获取时查看提示或已有缓存，不把失败当成已获取内容。

「打开应用内网页」打开独立预览窗口。它的登录状态按资料隔离，不自动复制 Chrome Cookie；可后退、前进、刷新、关闭，或通过「清除此资料的预览会话」清理。页面不能调用桌面的书签或文件命令。网页不兼容时可用「在 Chrome 中打开」交给外部浏览器。桌面按钮不能代替 Chrome 扩展的当前标签页授权手势。

## 可选本地语义检索

语义检索与普通搜索、聊天 AI 分别使用，默认关闭。当前源码已提供控制界面，但尚无真实模型相关性及性能验收，不能保证查询质量或 1 秒时延。

在「设置 → 语义检索」填写本机 Ollama 地址和已安装的向量模型。「检查本地模型」只核对模型元数据，不发送书签文本；应用不会自动下载模型。启用并「保存语义配置」本身也不会建立索引。没有本地模型或模型使用远程服务时，界面会明确不可用。

在书签页先勾选条目，再进入侧栏「语义检索」；也可明确选择一个目录及其子目录。点击「审查本次范围」，核对资料、模型、书签数量、输入裁剪和空间估算，再「确认并建立索引」。范围冻结为本次确认的书签，之后新增条目不会自动进入。输入仅含实际 Chrome 标题与已保存摘要，不包含网址、本地标签或备注字段；已经写入 Chrome 标题的编码标签仍属于标题文字。应用不会为索引自动抓取网页。

可以「暂停索引」「继续索引」，重启后未完成构建保持暂停，必须显式继续。修改已授权书签的标题或摘要后需要重新计算受影响条目；模型、版本、端点或维度变化时须重新审查并建立索引，不能混用旧向量。

在「描述想找的内容」输入文字，再点击「查询语义索引」或按 Enter 才发送查询。可取消请求。命中分数用于排序，不是准确率。切换资料或编辑查询会取消旧查询，旧结果不应进入当前来源。

「停用语义检索」停止请求并保留派生索引；「删除派生索引」经确认后删除范围、向量与进度，原书签、标签、备注、摘要和普通搜索保留。SQLite 文件不一定立即变小。需要评测时见 [固定数据与验收工具](../.trellis/tasks/10-10-mb-15-semantic-search/evidence/evaluation.md)。

## 诊断导出

在「设置 → Chrome 连接」底部点击「导出诊断 JSON」，在系统保存对话框选择位置。诊断文件只含应用、协议和数据库版本、系统类型及连接状态汇总，不含书签内容、资料名称、本机路径、密钥、日志或模型配置。不需要 Chrome 在线，不会自动生成或上传。浏览器界面预览不能导出。

完成写入后才显示「诊断文件已保存到所选位置」。取消不会生成文件；失败时检查保存位置的权限和可用空间后重试。默认名称为 `markbridge-diagnostics.json`。诊断文件用于排查连接问题；书签备份使用下方 HTML 或侧车 JSON。

## 操作历史、导出和条件撤销

侧栏「操作历史」按当前资料列出操作类型、时间、数量与结果，断线仍可查看。展开记录查看差异，批量记录可「查看逐项回执」。

| 结果 | 含义与下一步 |
| --- | --- |
| 已完成／已撤销 | 已观察到相应结果 |
| 等待执行／等待回执／正在撤销 | 等待回执，可重新查询 |
| 部分完成 | 有步骤未完成，先核对逐项结果 |
| 结果不确定 | 不能按失败直接重试，先核对 Chrome 和回执 |
| 撤销存在冲突 | 后续值与预期不同，外部改动保持不变 |
| 执行失败 | 查看失败原因，解决后重新审查需要的操作 |

「标记已核对」记录人工检查，不会把不确定或部分结果改为成功。

撤销需要实时连接。点击「撤销此记录」，阅读完整撤销差异，再「确认条件撤销」。应用逐项检查当前值是否仍满足恢复条件，不覆盖后来在 Chrome 中作出的外部修改。删除后的恢复可能产生新的书签编号，应用负责恢复关联的本地数据。不能撤销的项目会保留冲突说明。例如，新建文件夹后又在 Chrome 中加入内容，撤销新建会被拒绝，新增内容会保留。

从历史的「备份导出」或「设置 → 备份导出」打开导出页，先确认「书签来源」：

- **导出 HTML：** 保存标题、网址、文件夹和顺序，可供浏览器导入。
- **导出侧车 JSON：** 已配对资料可保存本地标签、备注、摘要和身份信息。独立文件镜像没有这一项。

选择格式后，在系统保存对话框选择位置。只有完成写入后才显示「文件已保存到所选位置」；取消显示未生成文件，失败可检查权限和可用空间后重试。导出使用点击保存时捕获的完整本地缓存，显示其时间和版本，断线也可导出。HTML 和侧车 JSON 不等于应用提供任意全库导入恢复。

## 整理与 AI

先在书签页选中条目，再进入「整理」；也可选「指定目录」，选择目录后点击「使用此目录」，范围包含后代书签。查看顶部的资料、范围和书签数量。切换范围会清除未确认审查；仅进入整理不会自动扫描、抓取或请求模型。

### 重复与链接

「检查重复」列出当前范围的候选。选择保留项，点击「预览清理」，核对待删项与本地数据处理，再「确认清理」。保留项备注保持不变，标签取并集，摘要不合并；不同备注会列为冲突供审查。

「检查链接」可取消。403、429、超时或受限地址可能显示「状态未知」，不能据此认定书签已失效。链接检查不会自动删除书签。整理期间可切回书签，再回来查看结果；已确认的变更在操作历史中可追溯。

### AI 设置与建议

AI 默认关闭，普通书签管理不依赖它。在「设置 → AI」勾选「启用 AI」，选择 Ollama 或兼容端点，填写端点和模型并「保存配置」。密钥通过「保存密钥」进入系统凭据存储；可「清除凭据」。保存配置不会连接模型；点击「测试连接」才发送测试提示。

生成前查看整理页显示的端点、模型和发送范围：

- **单条建议：** 主动点击「生成建议」时，发送该书签标题、网址和已有缓存正文的限长片段；不发送本地备注，也不会为此抓取网页。建议可编辑，勾选要保存的标题、标签、摘要后「确认这条建议」。标题写回需要实时连接，本地标签和摘要可以独立保存。
- **AI 文件夹：** 「提出文件夹」只发送范围前 200 项的限长标题和网址；审查目录名称后「确认目录」，再「生成分配」。分配会分批使用整个明确范围。审查各条目标和拒绝选项，最后点击「应用」才创建目录并移动书签。

生成中的「取消」终止请求，晚到建议不会自动应用。已确认的浏览器变更要看实际回执，「停止剩余步骤」不能撤回已执行部分。来源内容变化后，旧方案不能直接应用；重新选择范围并生成、审查。

本轮合成模型服务测试只验证传输、取消和审查流程，**不代表真实模型质量已验收**。跨设备同步继续由用户原有工具（如 Floccus）负责；Chrome 标题和目录变更可能被这些工具同步，本地备注、摘要等侧车数据不会自动同步。外部同步兼容性须看独立验收结果。
