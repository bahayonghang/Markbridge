# ADR-0003: 侧边栏独立布局偏好、目录树交互解耦与 Airy Glass 材质深度修正

ADR-0002 确立了 `style:airy-glass`（`sky` 调色板）双浮动纸面框架，但实际落地后暴露出四类体验缺口：左侧主侧边栏宽度被锁死且宽屏不可折叠；目录树缺失独立展开/收起按钮，单击与展开强绑定且会误清搜索筛选；列表区、详情区、普通态行与输入框仍被不透明实色覆盖且全站未启用浮层磨砂，加之暗色内分割线偏硬、Windows 原生粗灰滚动条与未同步主题的系统标题栏，导致界面偏闷失真。我们决定将侧栏宽度与宽屏图标窄轨折叠状态独立持久化于 `markbridge.layout-preferences.v1`（与外观偏好 `markbridge.ui-preferences.v2` 隔离），在双纸底场缝隙放置无障碍侧栏分隔手柄；在目录树将独立折叠箭头、行单击选中、行双击切换与键盘聚焦职责彻底解耦；继续坚守 `style:airy-glass (sky)` 及纸面与虚拟列表行零 `backdrop-filter` 的 B10K 性能红线，但解除内部容器与输入框的不透明覆盖、仅对滚过其上的浮层启用 `backdrop-filter`（同屏不超过 6 处）、将纸内分割线弱化至低于外纸描边并定制细滚动条，同时通过仅限 `main` 窗口调用的 `set_window_theme` 命令同步原生 Windows 标题栏深/浅外观。

## Considered Options

- **将侧栏宽度写入 `markbridge.ui-preferences.v2`**：虽可少维护一个存储键，但会破坏现有 `v2` 契约并导致「恢复默认外观（仅重置主题、字体和字号）」误清空用户的侧栏布局宽度。
- **对左右两张主纸面整体启用 `backdrop-filter`**：视觉模糊更重，但违背 `style:airy-glass` “纸面不模糊”原则并对万级书签（B10K）虚拟滚动合成帧率带来持续负担。
- **接入 Windows 11 原生 Mica / Acrylic 或自绘无边框标题栏**：可获得系统桌面穿透感，但引入窗口合成、系统拖拽贴靠、高对比度与多 DPI 兼容风险，收益不及轻量的 `set_window_theme` 原生标题栏深/浅同步。
- **同步开放右侧详情面板拖拽调宽**：会增加三栏并发夹紧与窄屏状态复杂度，按需打开的响应式宽度已满足详情阅读需求。

## Consequences

- 既有外观偏好 `markbridge.ui-preferences.v2` 与「恢复默认外观」语义保持完全兼容；侧栏宽度与折叠态独立演进、失效静默回退默认 `256px` 展开态。
- 取消列表行与输入框不透明实色后，对比度校验须以「纸面叠底场及色斑」最差合成背景为准，确保持续满足 WCAG 2.2 AA（正文 ≥ 4.5:1、控件边界 ≥ 3:1）。
- 全站保持原生窗口装饰与系统交互习惯，仅新增一条受信任主窗口校验保护的 Rust 命令 `set_window_theme`，不改动浏览器扩展协议或任何共享 DTO。
