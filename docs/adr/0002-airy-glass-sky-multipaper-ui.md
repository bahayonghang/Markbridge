# ADR-0002: 还原 Airy Glass（Sky 调色板）多纸面架构并统一全工作台控件系统

当前工作台虽声明采用轻盈毛玻璃，但实际将单张纸面铺满整个窗口并移除底场色斑，二级设置分类栏涂满薄荷绿反而压过一级主导航，蓝色品牌图标与薄荷绿强调色冲突，全站充斥细灰框药丸按钮且超宽屏设置页控件间距拉裂至 400px 以上。我们决定基于 `design-atlas` 将 `style:airy-glass` 切换至匹配蓝标的 `sky` 调色板浅/深双色合同，在宽屏（`≥960px` 且高 `≥551px`）还原左导航纸与右主工作台纸的双浮动纸面结构（底层绘制 3 个非模糊径向渐变色斑的 160° 底场并留出 12–16px 底场缝隙，纸面与虚拟列表行永不启用 `backdrop-filter`）；左导航主菜单顶置顺排并移除底部静态文字底栏，改在左导航底部放置实时连接状态胶囊；设置页保留左侧二级分类竖栏但改为透明融入右侧纸面去色块，表单收紧至 `760px` 紧邻分类栏并用无框 `well` 分组，全工作台统一采用主蓝实底按钮、无框 `control-fill` 次要按钮、真 Segmented Control 与 12px 柔边输入框。

## Considered Options

- **切换为 Linear / Sleek 无毛玻璃纯平工作台**：可规避透明层处理，但会放弃既有的轻盈毛玻璃风格定位且造成较大视觉跳变。
- **设置页取消二级竖栏改用顶部水平分段标签**：虽能节省横向宽度，但五个设置分区切换频率低且多栏内容较长，保留融入纸面的左分类竖栏更符合桌面设置工作台心智。
- **书签详情在大屏拆为第三张独立浮动纸面**：在 `1100px–1360px` 宽度下多道外缝隙会明显挤压列表与详情阅读宽度，故决定详情面板保留在右侧主内容纸内并以柔和边界分隔。

## Consequences

- 取消大面积纸面 `backdrop-filter` 并仅按需用于滚过其下的浮层，既符合原目录设计规范，也保护万级书签（B10K）虚拟滚动帧率。
- 严格保留用户本机已安装字体、`12–20px` 精确字号与 `resolveAppearanceMetrics` 虚拟行高契约，以及 `<960px` / `640×480` / `prefers-reduced-transparency` / `forced-colors` 合规回退。
